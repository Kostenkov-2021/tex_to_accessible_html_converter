TeX to Accessible HTML Converter

A Windows application that converts LaTeX documents to HTML5 with Presentation MathML for visual display, screen readers, Braille output, and MathCAT.

Features

  • Accessible English and Russian wxPython interface.
  • Batch conversion of individual files or every .tex file in a folder.
  • Supports TeX Live and MiKTeX distributions; the supported conversion engines are LaTeX, LuaLaTeX, and XeLaTeX.
  • MathML repair and structural validation before replacing existing output.
  • HTML-only, logs, temporary-files, and logs-plus-temporary-files retention modes.
  • The original TeX source is never modified.

Requirements

The installed application requires TeX Live or MiKTeX with make4ht, TeX4ht, and the packages used by the source document.

Using the application

  1. Use Add .tex for individual files or Add folder for all TeX files directly in a folder.
  2. Select the destination, TeX distribution, engine, time limit, and files to keep.
  3. Select Convert.

Folder selection is non-recursive. By default only the validated HTML is retained. Logs are written to name.html.logs/run-*; complete build trees to name.html.temporary/run-*. Use Open documentation or press F1 to reopen this page.

Command line

The CLI accepts files and folders and does not require wxPython:

python tex_to_accessible_html_cli.py INPUT [INPUT ...] [--recursive]
  [-o OUTPUT_DIR] [--engine latex|lualatex|xelatex]
  [--mode default|draft] [--tex-distribution auto|texlive|miktex]
  [--timeout SECONDS] [--keep html|logs|temporary|all]

Directories are non-recursive unless --recursive is used. Exit status 0 means complete success, 1 means at least one conversion failed, and 2 means invalid input.

How it works

The converter stages the source tree in an isolated directory and never changes the original. It applies limited TeX4ht compatibility adaptations to that copy, runs make4ht with a bounded subprocess, normalizes the HTML, repairs known MathML fidelity defects, and validates MathML structure. Only a validated result replaces the destination. The GUI and CLI call the same pipeline. Separate modules handle process control, TeX compatibility, MathML repair, validation, localization, and presentation.

Python code quality

Public modules, classes, functions, and methods follow PEP 257 and use Python type annotations. Development checks use Ruff for formatting and static analysis, mypy for type checking, and pytest for regression tests.

Language

Use the Language selector to switch between English and Russian. Files and conversion settings are retained, and the selection is saved for future launches.

Security

TeX can execute powerful commands. Do not process untrusted documents outside an isolated environment. The converter applies compatibility changes only to a temporary staged copy.

Feedback and contributing

Report bugs and request features in GitHub Issues. Contributions are welcome. Include a minimal TeX example, distribution, engine, and diagnostic logs when appropriate; never publish confidential documents or logs.
