Конвертер TeX в доступный HTML

Приложение для Windows преобразует документы LaTeX в HTML5 с Presentation MathML для визуального отображения, программ экранного доступа, брайлевского вывода и MathCAT.

Возможности

  • Доступный интерфейс wxPython на английском и русском языках.
  • Пакетная конвертация отдельных файлов или всех .tex-файлов в папке.
  • Поддерживаемые дистрибутивы LaTEx: TeX Live и MiKTeX; поддерживаемые движки распознавания: LaTeX, LuaLaTeX и XeLaTeX.
  • Исправление и структурная проверка MathML до замены существующего результата.
  • Четыре режима сохранения результата и временных файлов: только HTML, журналы, временные файлы, журналы и временные файлы.
  • Исходный файл TeX никогда не изменяется.

Требования

Для установленного приложения требуется TeX Live или MiKTeX с make4ht, TeX4ht и пакетами, используемыми исходным документом.

Использование

  1. Добавьте отдельные файлы кнопкой Добавить .tex или файлы непосредственно из одной папки кнопкой Добавить папку.
  2. Выберите папку назначения, дистрибутив TeX, движок, время и сохраняемые файлы. КЕсли за указанное время конвертация не завершилась, попробуйте ещё раз, увеличив время.
  3. Нажмите Конвертировать.

Поиск в папке не рекурсивный. По умолчанию сохраняется только проверенный HTML. Журналы находятся в имя.html.logs/run-*, полные рабочие папки — в имя.html.temporary/run-*. Чтобы снова открыть эту страницу, нажмите Открыть документацию или F1.

Командная строка

CLI принимает файлы и папки и не требует wxPython:

python tex_to_accessible_html_cli.py ВХОД [ВХОД ...] [--recursive]
  [-o ПАПКА] [--engine latex|lualatex|xelatex]
  [--mode default|draft] [--tex-distribution auto|texlive|miktex]
  [--timeout СЕКУНДЫ] [--keep html|logs|temporary|all]

Папки обрабатываются рекурсивно только с --recursive. Код 0 означает полный успех, 1 — ошибку хотя бы одного файла, 2 — неверный ввод.

Как работает программа

Конвертер копирует дерево исходников в изолированную папку, не меняя оригинал. К копии применяются ограниченные изменения совместимости TeX4ht, затем make4ht запускается с ограничением времени, указанном перед началом конвертации. HTML нормализуется, известные искажения MathML исправляются, структура MathML проверяется. Файл назначения заменяется только проверенным результатом. GUI и CLI используют один конвейер; отдельные модули отвечают за процессы, совместимость TeX, исправление и проверку MathML, локализацию и интерфейс.

Качество кода Python

Публичные модули, классы, функции и методы оформлены согласно PEP 257 и используют аннотации типов Python. Для разработки применяются Ruff для форматирования и статического анализа, mypy для проверки типов и pytest для регрессионных тестов.

Язык

Переключатель языка позволяет выбрать английский или русский язык. Список файлов и параметры конвертации сохраняются, выбранный язык используется при следующих запусках конвертора.

Безопасность

TeX позволяет выполнять мощные команды. Не обрабатывайте недоверенные документы вне изолированной среды. Изменения совместимости применяются только к временной копии конвертируемого файла, сам файл остаётся неизменным.
