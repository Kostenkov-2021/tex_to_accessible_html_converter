# Конвертер TeX в доступный HTML

Приложение для Windows преобразует документы LaTeX в HTML5 с Presentation MathML. Доступны графический интерфейс и командная строка. Формулы остаются визуальными и доступны программам экранного доступа, брайлевскому выводу и MathCAT, если это поддерживается используемой программой экранного доступа.

> [!IMPORTANT]
> Проект находится на стадии alpha. TeX позволяет выполнять мощные команды, поэтому недоверенные документы следует обрабатывать только в изолированной среде.

## Возможности

- доступный графический интерфейс wxPython на английском и русском языках;
- переключение языка непосредственно в окне с сохранением выбора;
- пакетная обработка отдельных `.tex`-файлов или всех `.tex`-файлов в папке;
- поддержка TeX Live и MiKTeX;
- движки LaTeX, LuaLaTeX и XeLaTeX;
- встроенные стили и явные пространства имён MathML;
- проверка структуры и типовых искажений MathML до замены существующего результата;
- ограничение времени обработки и четыре режима сохранения: только HTML, журналы, временные файлы, журналы и временные файлы;
- работа с временной копией: исходный `.tex` не изменяется.

> [!WARNING]
> Журналы работы программы и временные файлы могут занимать много места на диске. Сохраняйте журналы и временные файлы только в случае, если вы столкнулись с ошибками конвертации.

## Требования

- Python 3.10 или более поздняя версия при запуске из исходного кода;
- wxPython;
- TeX Live или MiKTeX с `make4ht`, TeX4ht и пакетами, используемыми исходным документом.

## Запуск

```powershell
python -m pip install wxPython
cd .\tex_to_accessible_html_converter
python .\tex_to_accessible_html_gui.py
```

Добавьте отдельные файлы кнопкой **Добавить .tex** или все `.tex`-файлы непосредственно из одной папки кнопкой **Добавить папку**. Выберите место сохранения, параметры и режим **Сохраняемые файлы**, затем нажмите **Конвертировать**. Поиск в папке в GUI не рекурсивный. По умолчанию сохраняется только HTML рядом с исходным документом.

## Командная строка

Консольный интерфейс не загружает wxPython и подходит для автоматизации и серверов:

```text
python tex_to_accessible_html_cli.py ВХОД [ВХОД ...] [--recursive]
  [-o ПАПКА] [--engine latex|lualatex|xelatex]
  [--mode default|draft] [--tex-distribution auto|texlive|miktex]
  [--timeout СЕКУНДЫ] [--keep html|logs|temporary|all]
```

Входом может быть файл или папка. Папка обрабатывается рекурсивно только с `--recursive`. Код завершения: `0` — все преобразования успешны, `1` — хотя бы одна ошибка, `2` — неверные аргументы или отсутствие файлов TeX.

```powershell
python .\tex_to_accessible_html_cli.py .\лекции --recursive -o .\html --keep logs
```

## Как работает программа

Для каждого документа `converter.py` создаёт изолированную рабочую папку и копирует туда дерево исходников, не изменяя оригинал. `tex_compatibility.py` вносит только ограниченные изменения совместимости TeX4ht во временную копию. `conversion_process.py` запускает `make4ht` с выбранным движком и контролирует ограничение времени. Затем HTML нормализуется, `mathml_fidelity.py` исправляет известные искажения MathML, а `mathml_validation.py` проверяет структуру. Файл назначения заменяется только проверенным результатом. Журналы сохраняются в `*.html.logs/run-*`, полная временная рабочая папка — в `*.html.temporary/run-*`.

`tex_to_accessible_html_gui.py` реализует GUI, а `tex_to_accessible_html_cli.py` — командную строку. Оба интерфейса используют один и тот же конвейер конвертации, исправления и проверки файлов.

Нажмите **Открыть документацию** или клавишу **F1** в главном окне, чтобы открыть локальную HTML-документацию на текущем языке интерфейса в браузере по умолчанию. Эта возможность работает без подключения к Интернету как в автономном дистрибутиве, так и после установки приложения. Документация Markdown остаётся только в репозитории исходного кода и не включается в бинарный дистрибутив.

## Язык интерфейса

Английский является исходным и резервным языком. Русский перевод хранится в GNU gettext-каталоге. Язык можно изменить в верхней части главного окна; файлы и выбранные параметры при переключении сохраняются.

Переменная окружения имеет приоритет над сохранённым выбором:

```powershell
$env:TEX_ACCESSIBLE_HTML_LANGUAGE = "ru"  # либо "en"
python .\tex_to_accessible_html_gui.py
```

Внешние программы TeX могут продолжать выводить сообщения на языке, выбранном в их собственных настройках.

## Структура проекта

- `tex_to_accessible_html_gui.py` — доступный графический интерфейс;
- `tex_to_accessible_html_cli.py` — интерфейс командной строки;
- `converter.py` — общий конвейер конвертации;
- `conversion_process.py` — запуск процессов с ограничением времени и журналированием;
- `tex_compatibility.py` — изолированные адаптации совместимости TeX4ht;
- `mathml_fidelity.py` — исправление известных искажений MathML;
- `mathml_validation.py` — структурная проверка MathML;
- `localization.py` и `locales/` — выбор языка и каталоги GNU gettext;
- `tests/test_*.py` — модульные тесты, не требующие установки TeX.

## Сборка Windows-установщика

Установите инструменты разработки и [Inno Setup](https://jrsoftware.org/isdl.php), затем выполните:

```powershell
uv pip install --python .\tex_to_accessible_html_converter\.venv\Scripts\python.exe `
  -r .\packaging\requirements-build.txt
.\packaging\build_installer.ps1
```

Автономное приложение будет создано в `dist\TeXToAccessibleHTML`, установщик — в `dist\installer`. Английская и русская документация включаются в каталог `docs`. TeX Live или MiKTeX устанавливаются отдельно.
